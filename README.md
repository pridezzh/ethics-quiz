# 工程伦理题库

工程伦理课程复习资料，包含 **15讲作业题（303道）** 和 **一套期末试题（25道）**，共328道题。

**[打开在线题库](https://pridezzh.github.io/ethics-quiz/)** · [直接查看期末题](https://pridezzh.github.io/ethics-quiz/?bank=exam) · [搜索全部题目](https://pridezzh.github.io/ethics-quiz/?bank=all)

## 题库内容

| 分类 | 内容 | 文本资料 |
|---|---|---|
| 作业题 | 15讲，303道题 | [题目与参考答案](questions/homework.txt) |
| 期末试题 | 单选10道、多选10道、判断5道，每题4分 | [试题、参考答案与解析](questions/final-exam.md) |

## 使用方法

1. 选择“作业题”“期末考试”或“全部”，输入关键词检索。多个关键词用空格分隔，表示同时包含。
2. 按题型或作业章节筛选；开启“自测模式”可先隐藏答案，再点击题目查看。
3. 复制地址栏链接可分享当前筛选结果；下载 [index.html](index.html) 后，可用浏览器直接打开，离线检索。

## 答案说明

作业题保留原稿参考答案；期末题附参考解答，其中第3题答案待核实。答案仅供复习参考，以课程讲义或教师公布的答案为准。
