## 使用

- 顶部切换“作业题”“期末考试”或“全部”，输入关键词即时搜索。
- 支持按章节、题型筛选，关键词高亮、自测和复制；期末题附简短解析。
- 搜索与筛选状态可通过网址分享，例如 `?bank=exam&q=正当性`。
- 下载 `index.html` 用浏览器直接打开即可离线使用，题库已内嵌。
