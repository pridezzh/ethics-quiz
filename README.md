# 工程伦理 · 题库速查

[打开在线题库](https://pridezzh.github.io/ethics-quiz/)

15 讲，共 303 题：单选 109 题、多选 122 题、判断 72 题。

- 输入关键词即时检索题干、选项、答案和章节；多个关键词用空格分隔。
- 支持按章节、题型筛选，答案高亮、自测和一键复制。
- 支持手机访问；筛选状态可通过网址分享。
- 按 `/` 聚焦搜索框，按 `Esc` 清空。

## 离线使用

下载 `index.html`，用浏览器直接打开即可。题库数据已内嵌，无需安装依赖。

## 文件

- `index.html`：完整网页与内嵌题库。
- `.nojekyll`：GitHub Pages 静态发布标记。
- `README.md`：使用说明。

题目与参考答案沿用上传时提供的题库，未逐题核验。
